# Github CLI

## Extensions

- [gh-dash](https://www.gh-dash.dev): A dashboard for managing GitHub repositories and issues.
- [gh-copilot](https://github.com/features/copilot): An AI-powered code completion tool that helps you write code faster and with fewer errors.
- [gh-aw](https://github.com/github/gh-aw): GitHub Agentic Workflows
- [gh-stack](https://github.com/github/gh-stack): GitHub Stacked PRs
